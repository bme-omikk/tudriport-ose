# Tudománymetriai riportkészítő

Ezen a munkaterületen a BME számára és koordinálásában készült tudománymetriai táblázatokat generáló keretrendszer érhető el.

A rendszert a BME és az Alkotók megállapodása alapján nyílt forráskódú projektként közzétették a GNU AGPL licensz szerint.

Az alapkoncepció az, hogy az MTMT mindenkori rendszeréből nyert nyilvános
publikációs adatokat előfeldolgozva tárolja a rendszer, amiből
majd ad-hoc lekérdezéseket tesz lehetővé.

## Struktúra

 * `docs/`: a rendszer különféle dokumentációi.
   Érdemes egy-egy dokumentációt külön alkönyvtárba, azon belül is egy README.md fájlba tenni,
   így a könyvtár megnyitásakor a GitHub webes felülete automatikusan rendereli a dokumentumot.
   Mellette elférnek a képek, esetleges további fejezetek.
    * `kovetelmeny-specifikacio/`: a rendszer követelmény-specifikációja.
